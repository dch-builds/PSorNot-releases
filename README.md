# PS or Not

**DualSense ou manette Xbox ?** PS or Not te dit quelle manette sortir pour chaque jeu PC.

- Met en avant les fonctions exclusives de la DualSense que le jeu exploite : retour haptique, gâchettes adaptatives,
  gyroscope, light bar, haut-parleur.
- Explique comment les activer : câble USB, Steam Input, outils tiers (DSX…).
- Analyse tes jeux installés : Steam, Epic Games, GOG, EA, Ubisoft, Battle.net, Xbox et tes propres dossiers.

## Installation

Avec WinGet :

```powershell
winget install dch-builds.PSorNot
```

Ou télécharge `PSorNotApp-win-Setup.exe` depuis la [dernière release](../../releases/latest).
L'installation est par utilisateur (pas de droits administrateur) et installe le runtime .NET 10 Desktop si besoin.
L'application se met à jour toute seule.

> Windows peut afficher « Windows a protégé votre ordinateur » au premier lancement de l'installeur (il n'est pas
> signé) : clique sur « Informations complémentaires » puis « Exécuter quand même ».
